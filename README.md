# kompas — КОМПАС-3D для Claude (Claude Code, Cowork, чат Claude Desktop)

Claude работает с документами КОМПАС-3D через COM API: создаёт и правит чертежи, фрагменты и детали,
ставит размеры, заполняет основную надпись и **сам смотрит на результат** — документ рендерится в картинку
(временный файл удаляется сразу, на диске ничего не остаётся).

Состав:
- MCP-сервер `kompas` (`server.py`) — инструменты `kompas_*`; главные правила работы зашиты в его инструкции;
- скилл `kompas` (`skills/kompas/SKILL.md`) — подробный порядок работы, координаты листа, ЕСКД, диалоги;
- скилл `kompas-pneumo` (`skills/kompas-pneumo/SKILL.md`) — технологические и пневмосхемы: каталог обозначений
  (по таблице к курсовому проекту «Компрессорные станции и установки», ГОСТ 2.786, 2.704, 21.205), размеры под A1,
  порядок построения, позиционные обозначения;
- расширение Claude Desktop `dist/kompas.mcpb` — тот же сервер для обычных чатов (собирается скриптом).

## Требования

- Windows, КОМПАС-3D (проверено на v25, в том числе учебной версии).
- Python 3.10+ в `PATH` (команда `python`) с зависимостями:

```bash
pip install mcp pywin32 pillow pydantic comtypes
```

## Где что работает

Сервер общается с КОМПАСом на этом компьютере, поэтому нужен клиент, который запускает локальные MCP-серверы.

| Где | Как подключить | Инструменты | Скилл |
|---|---|---|---|
| Claude Code (CLI, вкладка Code) | плагин из маркетплейса | да | да |
| Cowork в Claude Desktop | плагин через Customize → Plugins | да (сессии на вашем компьютере) | да |
| Обычный чат Claude Desktop | расширение `.mcpb` (+ плагин для скилла) | да | с плагином |
| claude.ai в браузере, мобильное приложение | — | нет: туда локальный сервер не дотянуться | с плагином |

### Claude Code

```bash
claude plugin marketplace add MyNameIsEldar/kompas-mcp
claude plugin install kompas@kompas-local
```

Перезапустите сессию. Проверка — «проверь подключение к КОМПАСу».

### Cowork и аккаунт Claude (чат, Cowork, Claude Code)

Claude Desktop → **Customize → Plugins → Add → Add marketplace** → `MyNameIsEldar/kompas-mcp` → установить
плагин **kompas**. Плагин сохраняется в аккаунт: скилл работает в чате, Cowork и Claude Code, а MCP-сервер
(«Runs in each session») — в Cowork и Claude Code. Если плагин уже установлен из CLI, в Claude Code
удалите одну из копий, чтобы не было двух одинаковых серверов: `claude plugin uninstall kompas@kompas-local`.

### Обычный чат Claude Desktop

```bash
python scripts/build_mcpb.py
```

Откройте `dist/kompas.mcpb` двойным щелчком (или Claude Desktop → Settings → Extensions → Install extension)
и нажмите «Установить». Инструменты `kompas_*` появятся в чатах.

### Обновление после правок кода

Поднимите `version` в `.claude-plugin/plugin.json`, затем:

```bash
claude plugin marketplace update kompas-local
claude plugin update kompas@kompas-local
python scripts/build_mcpb.py
```

Для аккаунта (Cowork) — запушьте изменения и нажмите **Check for updates** у маркетплейса в Customize → Plugins.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `kompas_status` | Подключиться (при необходимости запустить КОМПАС), версия и список документов |
| `kompas_new`, `kompas_open`, `kompas_activate`, `kompas_save`, `kompas_close` | Документы |
| `kompas_preview` | Картинка документа: весь лист, участок `region` в мм, 3D-ориентация |
| `kompas_window_screenshot` | Снимок окна КОМПАСа (интерфейс, диалоги) |
| `kompas_dialogs` | Найти модальный диалог, прочитать текст и кнопки, нажать кнопку |
| `kompas_draw` | Отрезки, окружности, дуги, прямоугольники, полилинии, точки, текст |
| `kompas_dimensions` | Линейные, диаметральные, радиальные, угловые размеры (с привязкой к дуге/окружности) |
| `kompas_list_objects`, `kompas_delete` | Объекты вида с координатами и reference; удаление |
| `kompas_stamp`, `kompas_sheet`, `kompas_views` | Основная надпись, формат листа, виды с масштабом |
| `kompas_3d_feature` | Эскиз на плоскости + выдавливание/вращение (добавить или вырезать) |
| `kompas_symbols_catalog` | Каталог условных обозначений для пневмо- и технологических схем (37 символов) |
| `kompas_place_symbols` | Вставить обозначения (компрессоры, фильтры, клапаны, теплообменники, ресиверы…) — каждое одним макрообъектом, с портами |
| `kompas_pipes` | Трубопроводы между портами, ортогонально, со стрелками; среда `kind` — газ, масло, дренаж, сброс на свечу/факел, вода, воздух, импульсная, линия управления (свой стиль или обозначение в разрывах линии по ГОСТ 2.784) |
| `kompas_legend` | Блок «Условные обозначения» только из реально использованных на листе видов линий (и, по желанию, символов) в заданной точке |
| `kompas_check_sheet` | Автопроверка листа: текст поверх линий и символов, концы труб мимо портов, линии внутри кружков КИП — со списком координат и `region` для `kompas_preview` |
| `kompas_run_python` | Произвольный код против API7/API5 — для всего остального |
| `kompas_api_search` | Поиск интерфейсов, методов и констант API КОМПАСа |

## Как это устроено

- Все COM-вызовы идут через один поток (`kompas_com.ComWorker`).
- Пока операция выполняется, сервер раз в секунду проверяет, не заблокировано ли окно КОМПАСа
  модальным диалогом. Если да — вызов сразу возвращает текст диалога и его кнопки (MCP выполняет
  вызовы по очереди, поэтому ждать тайм-аута нельзя). Кнопку нажимает `kompas_dialogs` — через
  Win32 или UI Automation (диалоги КОМПАСа v25 сделаны на WPF).
- Для просмотра используется растровый экспорт API5 (`SaveAsToRasterFormat`) — он работает без
  диалогов, даже если окно свёрнуто.
- Учебная версия КОМПАСа не запускается через `CoCreateInstance`, поэтому сервер при необходимости
  запускает exe (путь из реестра) и подключается к запущенному экземпляру.

## Тесты

Тесты работают с живым КОМПАСом и создают в нём документы. Во время `dialog_test.py` ничего не нажимайте в КОМПАСе.

```bash
python tests/smoke_test.py
python tests/dialog_test.py
python tests/scheme_test.py
```

`tests/scheme_unit_test.py` проверяет разрывы под обозначения сред, порты и геометрию проверки листа без КОМПАСа.

Символы, трубы и легенда — макрообъекты с меткой в имени (`kmcp:{…}`: из чего и где построены). По ней
`kompas_legend` и `kompas_check_sheet` узнают среды и порты. У элементов, нарисованных до появления меток или
вручную, проверяются только наложения текста и кружки КИП.
